# Landing page demonstrativa para advocacia

Projeto demonstrativo em Next.js + TypeScript, sem banco de dados.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000

## Importante antes de publicar

- Substituir nome, número da OAB, áreas de atuação, formação, contatos e endereço pelos dados reais e comprováveis do profissional.
- Revisar toda a copy com o advogado.
- A versão demonstrativa está configurada como `noindex` para não ser indexada pelo Google.
- Só habilitar indexação após aprovação e revisão final de SEO/publicidade jurídica.
